Aoide Sidecar

Relays the Aoide curation store's op log between a user's devices. Playlists, folders, likes, play history and queue state sync here; the music library itself stays Jellyfin's.

A client with a long offline backlog splits it across several pushes.
Largest single row. A queue_state row holding a very long queue is the realistic maximum.
Deepest nesting a row may contain. Bounded because clients reject an over-nested pull response whole, which would stall sync on every device.
Off by default. Rewrites Jellyfin playlists from Aoide unattended; run one export by hand first.
